# Data Dictionary

## Dataset: E-Commerce Returns & Sustainability

| Column | Description |
|---|---|
| Order_ID | Unique identifier for each order |
| Product_ID | Identifier for the purchased product |
| User_ID | Identifier for the customer |
| Order_Date | Date when the order was placed |
| Product_Category | Category of the purchased product |
| Product_Price | Price of the product |
| Order_Quantity | Quantity purchased |
| Discount_Applied | Discount percentage applied |
| Shipping_Method | Shipping method used |
| Payment_Method | Payment method used |
| User_Age | Customer age |
| User_Gender | Customer gender |
| User_Location | Customer location |
| Return_Status | Whether the order was returned |
| Return_Reason | Reason for the return |
| Days_to_Return | Number of days before return |
| Order_Value | Order value after discount |
| Return_Cost | Recorded return-related cost |
| Profit_Loss | Order value minus return cost, as defined in the dataset |
| CO2_Emissions | Recorded CO2 emissions |
| Packaging_Waste | Recorded packaging waste |
| CO2_Saved | Recorded CO2 savings |
| Waste_Avoided | Recorded waste avoided |

## Analysis Period
January 2022 – August 2025
